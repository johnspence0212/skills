# Personal

Fork-only skills. Upstream does not have this bucket, and never will, which is why new work you actually own goes here instead of into `engineering/` or `productivity/`.

They ship in **this fork's** Claude plugin (the overlay appends them). They get no aihero.dev docs page. Keep [`ask-me`](./ask-me/SKILL.md) accurate when you add, rename, or remove one. Then run `node scripts/apply-fork-overlay.mjs`.

See [FORK.md](../../FORK.md).

- **[ask-me](./ask-me/SKILL.md)**: Ask which personal skill fits. For the upstream catalog, type `/ask-matt`.
- **[setup-john-skills](./setup-john-skills/SKILL.md)**: Run once per consumer repo. The command you type instead of `/setup-matt-pocock-skills`.
